### SpecterSaysHi (2026-10)

实时陪伴 · 自己训练的模型
实时数字人 · FeatherTalk · PyTorch · Agents SDK

一个我自己想要的、会说话的“人”。摄像头或手环发现我回来了，它会先开口；聊着天能顺手查网页，聊完把要点记下来，下次接着聊。脸是我自己训练的数字人模型，不是买来的接口。GPTSaysHi 是它的衍生版：直接拿 Windows 上 ChatGPT Live 的声音去驱动同一张脸；JesusSaysHi 是同一套框架上长出来的兄弟项目，换了角色，加了 RAG。名字来自 Harvey Specter。

嘴型模型用的是 FeatherTalk，在我那张打游戏的 4070 上训，素材是用 Grok 生成的说话视频。第二个角色一开始是接着第一个角色的权重训的，牙和嘴唇怎么调都对不上，最后干脆从头训了 100 轮才顺眼。从收到第一个 100 ms 音频包到画面出来，本机实测中位数大约 80 ms。记忆就是两层 JSON 文件，没上 Redis，用不着。

- JesusSaysHi（加了 RAG 的兄弟项目）: https://github.com/YeChen-coder/JesusSaysHi

### JesusSaysHi (2026-10)

RAG · 检索与评测
检索增强 · RAGFlow · Voyage rerank · OpenAI Realtime

SpecterSaysHi 的兄弟项目：一个可以开口聊天的耶稣，有声音也有数字人，有点像去告解。他先听你说完，再用自己的话回应，像一个从福音书里走过来的人；话说到合适的地方，会一字不差地说出他自己说过的话。

最硬的规矩是：引用必须是原文。四福音大约 3,800 节，塞不进 prompt，而模型凭记忆背还会背成别的译本，所以经文只能靠检索送到他嘴边：RAGFlow 混合检索加 Voyage 重排，55 道手工标注的问题里 hit@3 到了 95%，相关度低于 0.30 就干脆不引。每句回复都和检索到的原文、四福音全文逐字比对。为了不让人干等，他先说一句接住你的话，同时在后台“回忆”经文，你说完大约一秒多他就开口。危机检测放在模型外面，留出来的 15 条危机消息全部识别，没有误报。

- 仓库: https://github.com/YeChen-coder/JesusSaysHi
- SpecterSaysHi（同一套框架）: https://github.com/YeChen-coder/SpecterSaysHi

### EBOBotToDigitalPet (2026-09)

主项目 · 本地 + 云端
AI · IoT · OpenAI Realtime · AWS Fargate · Codex SDK

把家里那台 Enabot EBO 小机器人改成能看、能听、能聊天的陪伴。厂商的私有云协议被我转成普通的 RTSP 和 HTTP，再接上 Home Assistant 和 OpenAI Realtime。整套东西既能在家里的 Docker 上跑，也能整个搬上 AWS Fargate，但同一时间只允许一边控制机器人。

真正花时间的是“没人盯着的时候”。我写了一个诊断 Agent：先查健康状况，能自己恢复的就按规矩恢复，修不好的再交给 Codex 分两级分析；它只看得到过滤过的日志和只读代码，碰不到云端凭证，也碰不到 Docker。本地和云端切换之前，必须先确认另一边真的停了。AWS 那一半单独放在 EboBotOnAWSCloud。

### EBOBotQwenRealtime (2026-10)

第三代 · 只在本地跑
机器人 · Qwen Omni Realtime · Whisper · Frigate

EBO 的第三代，推倒重写，只在家里跑。语音换成了通义千问 Omni Realtime，不用先喊唤醒词；机器人也终于真正离开了充电座：看到人会开过去，家里人回来会主动打招呼，每天早上六点还会播一遍天气。

待机时用本地 Whisper 一句一句转写，再让一个小模型判断这句话是不是在跟它说：家里电视常开着，电视剧台词和家人之间的闲聊它得忍住不接，唤醒词则按读音模糊匹配。聊天时声音先进一条单独的语音识别，先判断这一轮该不该接、是不是只是杂音，再交给对话模型；机器人自己在动的时候麦克风关掉，免得把轮子声当成说话。记忆分两层，长期的家庭信息和会过期的近况分开放，不会再把“今天不舒服”反复问上一个礼拜。认出人以后它会转过去、开过去，五分钟没人就原地转一圈找，再找不到就自己回去充电。

- 仓库: https://github.com/YeChen-coder/EBOBotQwenRealtime
- 回到 v1: https://github.com/YeChen-coder/EBOBotToDigitalPet

### tianjin-chem-bank (2026-10)

AI + 文档工程
文档 AI · GLM · LaTeX · OOXML · SQLite

给我妈做的化学组卷工具。她把 Word 试卷丢进来，程序把题拆好、按知识点分好类；她可以直接改题、让 AI 出变式，最后导出一份还能接着编辑的 Word。题库里现在有一万多道题。

最难的是 Word 本身：同一个化学式，可能是 Word 公式，可能是老的 MathType 对象，也可能只是符号字体里的几个字。V2 把它们统一转成 LaTeX 存起来，导出时再变回 Word 原生公式。GLM 出的变式先过严格的结构检查，再过一轮独立核对，比如有道题文字写“锥形瓶”、图里画的却是分液漏斗，就被拦了下来。这次重构拆给四个 AI 编码会话并行写，靠一份共同的接口约定拼到一起。

- 仓库: https://github.com/YeChen-coder/tianjin-chem-bank

### 注意力刹车：Windows + Edge (2026-09)

系统工具
注意力管理 · Python · Win32 · Edge extension

两个配套的“刹车”：一个在 Windows 上限制某些程序，一个在 Edge 上限制某些网站。我有 ADHD，一进入心流就很难停下来，与其指望意志力，不如让环境替我踩刹车。

Windows 版按前台时间或进程运行时间计时，支持日程、一次性限时、直接关闭或遮住窗口，还有冷却期，系统关键进程不让选。网页版已上架 Edge 商店，可以按网址、或网址加关键词匹配；任何一条规则触发，所有规则一起锁住，免得我换个网站接着刷。
